# Beaglebone overview

## What is the SOC

- The SOC is the system on the chip.
- Back then, you'd have separate components for each thing:
    - DMA controllers
    - ram
    - flash memory
    - spi controller
    - much more.
- The components were separate chips, this would be cumbersome

- The **system on chip** will combine all of these controllers into one chip.
