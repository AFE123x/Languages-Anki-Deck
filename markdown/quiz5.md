## What are three key elements of wireless networks?

- Wireless Hosts
- Base Station
- Links

## What are the hidden terminal problem and exposed terminal problem?

- Hidden terminal problem: Other senders' information are hidden from the current sender, so the transmition to the same receiver will cause collisions
- Exposed terminal problem: The sender mistakenly thinks the medium is in use, so it unnecessarily defers the transmission

## What is the key difference between 2G and 3G cellular networks

- 3G has the data network work in parellel with the voice network

## What is the key difference between 3G and 4G cellular network

- All IP Core: IP packets tunneled from basestation to getaway.
- No separation between voice and data - all traffic carried over IP core to gateway. 

## What are the two approaches to handle the mobility?

- Let routing handle it, via advertising the address of mobile nodes
- Let the end system handle it with either Indirect routing or indirect routing.
    - indirect routing: mobile will go to the home agent, then to the remote.
    - direct routing. the correspondent will go directly to the remote. 

## In the Indirect routing, what's the difference between permament address and care of address?

- permanent address: address in home network, always used to reach mobile
- care of address: address of visited networks.

## What are the three kinds of attacks to break an encryption scheme?

- cipher-text only attacks: You only work with the ciphertext
- known-plaintext attack: the plaintext corresponds to ciphertext
- chose plaintext attacks: you can get the ciphertext for chosen plaintext.

## In a network authentication context, what is a nonce?

- Nonce is a number that can only be used once in a lifetime.
