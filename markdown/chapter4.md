# 4. Toolchain setup

## What is a development platform?

- A development platform provides an ecosystem of products that allow for a high level of abstraction across multiple vendors.
- This is beneficial for the long term development.

## What are evaluation kits?

- These are boards, fitted with a feature filled MCU with the sole intent of showing off the hardware. 
- Evaluation boards will also include a bunch of addition peripherals to let you try out hardware configurations.
