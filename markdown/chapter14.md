# 14. Switches

## Why would you want to use transistors in a microcontroller?

- Microcontroller pins alone are inadequate for heavier loads.
- What you can do is use transistors and pwm to drive the motor.

## Bipolar Junction Transistors

- These replaced the vacuum tube

![alt text](image.png)

- transistors let you control the flow of current between the collector and emitter.


- For NPN transistors, you apply power on base to allow flow
- For PNP transistors, you remove power on base to allow flow.


## MOSFET

- Mosfets are similar to transistors, where it provides a gate between the source and drain.

- N channel mosfets are similar to NPN transistors
- P channel mosfets are similar to PNP transistors.
